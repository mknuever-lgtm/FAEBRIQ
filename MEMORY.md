### Same day, later — the print-safety check was wrong, found and fixed properly
- Maurice pushed back on "trust the sample print" and asked to actually be sure first. That was the right call — the earlier verdict was built on two mistakes, not one conservative rule of thumb.
- **Mistake 1: the 0.33mm threshold was invented, not sourced.** Real number, found by searching: **Printify's own published DTG guideline is 2pt (0.706mm) minimum line thickness** — [help.printify.com](https://help.printify.com/hc/en-us/articles/43890557264529). More than double what I'd been using.
- **Mistake 2: I measured the wrong feature.** Earlier check used an isolated "O" glyph as a proxy. Measured directly on the real rendered file instead (scan every row, find the thinnest horizontal ink run, exclude solid-fill rows so the bar doesn't skew it) and the **actual headline text failed**, at the **serif feet** — the flat terminal at the base of a stroke, not the round-letter hairline the "O" test caught. Bodoni's serif feet are thinner than its round-letter hairlines; that's true at any size, so this is systemic to every letter, not a one-off. Measured worst case: 0.254mm on both "ERROR 404" and "STRAIGHT NOT" — well under 0.706mm.
- **Scaling up cannot fix this.** The failing/passing ratio (0.706/0.254 = 2.78×) is the same ratio the whole canvas would need to grow by, since serif-thickness scales with cap height. That means "STRAIGHT NOT" would need to print at **~42 inches wide** to clear the real minimum by size alone — not viable for a garment. This rules out "just make the label bigger," which is what the earlier (wrong) `SMALL_ELEMENT_BOOST` fix attempted.
- **Actual fix: alpha-mask dilation, not oversizing.** Render each text element as a standalone mask, apply `PIL.ImageFilter.MaxFilter(9)` (radius 4px) to it, then composite at constant fill colour. This adds a fixed pixel amount to every stroke's edges — meaning a 3px hairline nearly quadruples while a 40px+ stem barely changes, which is exactly the targeted correction needed.
