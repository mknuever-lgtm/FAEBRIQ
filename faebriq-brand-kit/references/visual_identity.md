# FÆBRIQ — Visual Identity

## Color tokens
- ink (ground):     #0D0D0D   (garments: #000000 true black)
- text:             #E8E8E8   (body/heading text — never pure white)
- display/wordmark: #C0C0C0   (silver)
- interactive accent: #4A9EFF (terminal blue — links, buttons, focus states; the only functional color)
- Pride Circuit bar (slim, hard-edge, 6 stripes, in order — desaturated editorial tone, not pure flag hex):
  coral #E8272A · amber #F47F20 · yellow #F9D426 · green #2AAA42 · blue #1D5BBE · purple #7B3FAA
- RETIRED / DO NOT USE: terracotta #C45500, "MKGH" palette, pure/unmuted pride-flag hex as primary accent.

## Typography
- Display / primary: Instrument Serif — wordmark (+0.06em tracking), statement phrases, headings.
- Body / UI: Archivo — copy, labels, buttons.
- Mono / technical: JetBrains Mono — prices, SKUs, terminal-style captions.
- RETIRED: Playfair Display. (This file specified Playfair until 2026-08-19; a direct side-by-side comparison against what's actually implemented sitewide showed Instrument Serif reads more distinctive and less like a generic "premium DTC" default — see `MEMORY.md` for the decision record.)

## The Pride Circuit bar
Thin horizontal bar of 6 equal hard-edged color blocks (small gaps). Slim, understated — never a thick block, never a smooth gradient (gradients don't embroider). Sits under/near the statement text.

## Image / render style (for AI image prompts)
"...matte-black background with subtle texture, dramatic low-key side lighting, deep soft shadows, delicate rim light, shallow depth of field, crisp macro focus, moody high-end e-commerce hero, photorealistic, 8k, no text overlays, no watermark."
Per product aim for ~6 images: 1 clean product, 2 on-model, 2 lifestyle (dev desk / queer art-market / city), 1 macro detail of the print or stitch.
