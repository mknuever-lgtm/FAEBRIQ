# FÆBRIQ Brand Kit

Apply this to everything FÆBRIQ. If a task involves FÆBRIQ copy, design, images, or marketing, follow this skill.

## 1. What FÆBRIQ is
Premium **queer + developer streetwear** built on one idea: **"Identity is a build process. We print status updates, not slogans."** Dark-tech minimalism for people who code by day and serve identity by night. Solo-founded in Toronto; sells to the **US** market, fulfilled **in the US** via Printify. Store: faebriq.com (Shopify).

## 2. Voice & tone
- **Wry, insider, understated.** Dev + queer in-jokes that land for the right people, subtle to everyone else.
- **Premium, not loud.** Confident; never try-hard, never corporate-Pride.
- **Year-round pride**, never June-only "rainbow capitalism."
- Write like a clever friend in the group chat, not a brand. Active voice, short, sharp.
- DO: "Subtle enough for stand-up, loud enough for the right people." DON'T: exclamation-hype, "shop now!!!", corporate allyship platitudes.

## 3. Visual identity
- **Ground:** near-black `#0B0B0D` (garments: true black). Text: white `#FFFFFF`.
- **Signature motif — the Pride Circuit bar:** a **slim, hard-edged 6-stripe** bar (NOT a gradient): `#E40303` `#FF8C00` `#FFED00` `#008026` `#24408E` `#732982`. Keep it thin and understated.
- **Typography:** **Playfair Display (serif)** = primary/display (wordmark, phrases, headings). A clean **geometric sans** = small-format / embroidery / UI labels (e.g., the cap).
- WARNING — NOT the brand: terracotta `#C45500`, the "MKGH" palette, Instrument-Serif-only, or Etsy. Those are retired/wrong. Ignore any older skill or file that references them.

## 4. Image aesthetic (renders/photos)
Matte-black studio background, dramatic low-key side lighting, deep soft shadows, rim light, shallow depth of field, macro focus on the print/embroidery, moody high-end e-commerce, photorealistic, no text overlays. On-model shots: stylish androgynous models, minimal settings. Keep the pride bar slim.

## 5. Audience personas
1. **The Queer Dev** (25-40, in tech) — wants to be subtly seen at work, loudly seen with their people.
2. **The tech-adjacent creative** — designers, founders, indie hackers in queer/tech spaces.
3. **The thoughtful ally** — buys because the brand is genuine year-round, not performative.

## 6. Messaging pillars
1. Identity-as-code (brand DNA).
2. Quiet signal — subtle pride, premium restraint.
3. Made-to-order, premium, US-printed.
4. Year-round values / "costly allyship" (a named share of Pride Circuit proceeds -> an LGBTQ+ org).
