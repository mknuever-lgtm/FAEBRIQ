# Model photo prompts, blank garments, 2026-10-04

For any free image tool (Gemini, ChatGPT, Canva, Bing Image Creator). One prompt per image. Ten images, one per product, each a different person.

Paste the prompt, generate, check the chest, and regenerate if there is ANY text, logo or graphic on the garment. Pick the best of 2 or 3 tries. Save as the file name shown. Aim for the largest size the tool gives (2048 x 2560 is ideal, 4:5 portrait). Any size works; I upscale.

When all ten exist, upload them here as a zip and I put the real prints on, angled to each pose, and swap them into Shopify.

## Shared line (already included in every prompt below)
Blank garment, no print, no text, no logo. Torso facing the camera within 25 degrees. Nothing covers the chest. Dark near-black studio backdrop with a soft charcoal glow, low-key moody light, but the garment front clearly lit so the fabric weave shows. Photorealistic, natural skin texture, confident relaxed expression. Portrait 4:5.
